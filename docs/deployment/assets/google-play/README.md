# Google Play 掲載アセット

Google Play Console の日本語（`ja-JP`）と英語（米国、`en-US`）の掲載情報で共通利用する掲載素材です。掲載文は Play Console のロケールごとに管理し、画像は言語に依存しないデザインにしています。

| ファイル                         | 用途                               | サイズ              |
| -------------------------------- | ---------------------------------- | ------------------- |
| `app-icon.png`                   | アプリアイコン                     | 512 × 512 px        |
| `feature-graphic.png`            | フィーチャー グラフィック          | 1,024 × 500 px      |
| `01-home.png` ～ `05-mypage.png` | スマートフォンのスクリーンショット | 各 1,080 × 1,920 px |

PNG は Play Console の形式・寸法要件に合わせています。アイコンとフィーチャー グラフィックは元の SVG を指定キャンバスへ直接レンダリングし、スクリーンショットは実装済みのアプリ画面を 480 × 853 px のスマートフォン表示で撮影した後、レイアウトを変えずに 1,080 × 1,920 px へ変換しています。フィーチャー グラフィック右側の盤面は `docs/product/assets/ten-product-overview.png` と `ten-ui-design-sheet.png` の盤面・配色を参照しています。広告のモック表示や開発用バッジは掲載画像へ含めていません。

Android本体に同梱するアイコンと起動画面は、リポジトリルートから `powershell -File scripts/generate-android-assets.ps1` を実行して同じアイコン素材から生成します。Play Console用画像だけ差し替えても、インストール後のアプリアイコンは更新されないため、AAB作成前にAndroid側のリソースも更新します。

スクリーンショットを再生成する場合は、アプリのローカル開発サーバー（`http://127.0.0.1:3000/`）を起動した状態で、リポジトリのルートから次を実行します。

```bash
pnpm --filter @ten/web exec node e2e/capture-google-play-assets.mjs
```

この撮影スクリプトは掲載画像専用のモック API とデモデータを使います。モックデータをアプリのリリースへ混入させないでください。`feature-graphic.svg` はフィーチャー グラフィックの編集用元データ、`render-icon.html` は既存の `apps/web/public/icon.svg` からアイコンを確認するための補助ファイルです。

## Console への登録順

1. `app-icon.png` をアプリのアイコンへ登録する
2. `feature-graphic.png` をフィーチャー グラフィックへ登録する
3. `01-home.png` ～ `05-mypage.png` をスマートフォンのスクリーンショットへ登録する
4. プレビューを確認する。特にアイコンのマスク後の余白、中央位置、スクリーンショットの文字サイズと上下の欠けを確認する
5. 日本語と英語（米国）の各ロケールで掲載文を入力する
6. 各ロケールのプレビューを確認し、掲載情報を未公開として保存する
